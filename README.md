# prompt-engineering-25BCON1699

This repository contains small programming practice examples for the Prompt Engineering coursework.

Programs included:

- `Session5/factorial.py` - Calculates the factorial of the number `5` using a loop and prints the result.
- `Session5/fibonacci.py` - Prints the first `10` numbers of the Fibonacci series.
- `Session5/even_odd.py` - Checks whether the number `10` is even or odd and prints the result.
- `Session5/largest.py` - Finds the largest value among `10`, `25`, and `15`.
- `Session5/palindrome.py` - Checks whether the text `madam` is a palindrome.
- `Session5/struct.c` - Demonstrates a C `struct` named `Student`, stores a sample student's name, roll number, and marks, then prints those values.
- `Session5/audit.md` - Audits the README and commit messages against the real repository files and Session 5 documentation instructions.

## Execution

Run these commands from the project directory.

### Python programs

```bash
python3 Session5/factorial.py
python3 Session5/fibonacci.py
python3 Session5/even_odd.py
python3 Session5/largest.py
python3 Session5/palindrome.py
```

### C program

Compile the C file first:

```bash
gcc Session5/struct.c -o struct
```

Then run it:

```bash
./struct
```

## Requirements

Required software:

- Python 3, for running the Python programs in `Session5`
- GCC or another C compiler, for compiling and running `struct.c`

No extra Python packages are required.
